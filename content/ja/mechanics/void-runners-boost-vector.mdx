## なぜVoid Runnersのブーストベクトルがすべてのランを決めるのか

Void Runnersは反応ゲームである前にモメンタムゲームだ。床は不安定で、ギャップは長く、生き延びる唯一の手段はすでに持っている速度と、その上に加えられる押し出しだけだ。だからこそ、Void Runnersのブーストベクトルは、あなたの道具箱の中で他のどの単一入力よりも重要になる。

ブーストベクトルとは、単に2つの情報、つまり押し出しの強さと、それが向く方向にすぎない。ほとんどのプレイヤーは前半しか考えない。最大の力でブーストを連打し、なぜレッジに引っかかったりデスプレーンへ流れたりするのか不思議に思う。ルートを実際に決めるのは方向の半分だ。

ベクトルで考えるようになると、ゲーム全体が変わる。「どうすればもっと速く行ける？」と問うのをやめ、「今、自分のモメンタムはどこを向いていて、0.5秒後にはどこを向いている必要がある？」と問い始める。この意識の切り替えが、ラッキークリアと再現可能なクリアの違いだ。

| 要素 | 何を制御するか | 無視するとどうなるか |
|---|---|---|
| 大きさ | ブーストが加える速度の量 | ギャップに届かないか、着地点を大きく通り過ぎる |
| 方向 | その速度が向かう先 | 壁、天井、何もない虚空へ流れ込む |
| タイミングウィンドウ | ブーストが実際に反映される瞬間 | 押し出しが遅れて着き、既存のモメンタムと衝突する |
| 減衰曲線 | 加わった速度がどれだけ早く抜けていくか | きれいなブーストでも長いルートが鈍く感じる |
| 重力との相互作用 | 押し出しが落下とどう合成されるか | 次のプラットフォームに必要な高さを失う |

減衰曲線は最も過小評価される要素だ。発動した瞬間は巨大に感じるブーストも、次のプラットフォームに着くころにはほぼ消えていることがある。ルートを計画するときは、ブーストを押した瞬間の距離だけでなく、ブーストの*後*に進む必要がある距離を考えよう。

## ブーストの種類とそれぞれが生み出すベクトル

すべてのブーストが同じ挙動をするわけではなく、互換性があるかのように扱うのは、ランを停滞させる最短経路の一つだ。それぞれの種類はわずかに異なる軸へ押し出し、それぞれが異なる状況とよく噛み合う。

| ブーストの種類 | 主軸 | 最適な用途 | 主なリスク |
|---|---|---|---|
| 地上ブースト | 水平、表面に沿う | 平坦な区間で生の速度を築く | 垂直セクション直前に無駄にする |
| 空中ブースト | カメラまたはキャラクターの向き | 飛行中の修正とジャンプの延長 | 意図せず下向きに放つ |
| チェインブースト | 前のブーストから複合される | プラットフォームが少ない長い開けた区間 | 早すぎる重ね掛けで方向制御を失う |
| 重力アシスト | 垂直、落下速度を利用 | 下層ルートやショートカットへのダイブ | 登り返せない下降にコミットする |
| 壁・レッジリダイレクト | 表面に対して垂直 | 速度を失わずに鋭く曲がる | 角度が浅すぎて壁で跳ね返る |

ほとんどのVoid Runnerビルドに当てはまる一般則：水平ブーストは距離を買い、垂直ブーストは選択肢を買う。そのセクションがどちらを求めているかわからないときは、もっと遠くへ行く必要があるか、もっと高く着く必要があるかを問おう。この一つの問いが、ほとんどのルート論争を解決する。

### コミットする前にベクトルを読む

コミュニティの報告は、速いプレイヤーに共通する習慣を一貫して説明している——彼らはギャップそのものではなく、ギャップの出口点を見る。目標到達点が、必要なベクトルを決める。虚空を狙えば、虚空へ舵を切ることになる。

### チェインが単発の大きなブーストに勝る場合

単発の大きなブーストは判断を一度しか与えない。小さなブーストのチェインは、修正する機会を何度も与える。慣れないルートでは、チェインするプレイヤーのほうが生き残りやすい。最初の押し出しが少し間違っていても、2回目か3回目で直せるからだ。一発最大の押し出しは、すでに暗記したルートのために取っておこう。

## タイミングウィンドウと入力規律

タイミングは、Void Runnersのブーストベクトルが数学の問題ではなくなり、筋肉記憶の問題になり始める場所だ。ベクトル自体は押すタイミングによって変わらない——しかし*結果*は変わる。なぜなら既存のモメンタムは一瞬ごとに異なるからだ。

| 押すタイミング | 典型的な結果 | 備考 |
|---|---|---|
| 弧の頂点 | ブーストが弧をきれいに延長する | ほとんどのプレイヤーにとって最も安全なウィンドウ |
| 上昇中 | ブーストが高さを加え、前進速度を犠牲にする | 垂直ルートに有用 |
| 下降中 | ブーストが重力と合成される | 速いが操作しにくい |
| 着地の瞬間 | ブーストが接触で部分的に相殺される | 通常は無駄な入力 |
| クールダウン中 | 入力が完全に落ちる | 最もよくあるサイレントな失敗 |

最後の行には注意が必要だ。ほとんどの実装では、クールダウン中に押されたブーストはキューに入らず、単に何もしない。クールダウン中にボタンを連打するプレイヤーは、ブーストしたと信じ、足りずに落ちるとゲームのせいにする。クールダウンを頭の中で数えるのは地味だが、どんな上級テクニックよりも多くの失敗ランを修正する。

## Void Runnersのブーストベクトルを壊すよくあるミス

ほとんどの失敗ランは、少数の繰り返しミスにさかのぼる。これらのうち2つか3つを直すだけで、新しい技を覚えるよりも大きな改善が得られることが多い。

| ミス | なぜ悪いか | 修正法 |
|---|---|---|
| カメラに向かってブーストする | 押し出しが前進モメンタムと衝突する | コミットする前にカメラを固定する |
| ブーストを早すぎる間隔でチェインする | 後のブーストがクールダウンに食われる | 入力の間に一拍置く |
| プラットフォームの中心を狙う | 修正する余地なく到着する | 手前の端を狙い、それからブレーキをかける |
| 落下速度を無視する | 重力が実効ベクトルを静かに回転させる | 角度を選ぶとき下降を考慮する |
| フルランばかり練習する | 失敗している区間を切り出せない | そのセクションを単独で練習する |

カメラのミスは、プレイヤーが最後に気づくものだ。多くのビルドではカメラが「前」を定義するため、カメラが振れている間に放ったブーストは意図しない方向を指す。一瞬を犠牲にしても、押す前にカメラを落ち着かせる習慣をつけよう。

## 練習ドリル、ルート計画、コミュニティの知見

Void Runnerのメカニクスが上達するのは、目的を持った反復からだ。ランダムなフルランはスタミナを築くが、狙いを定めたドリルはスキルを築く。

| ドリル | 目標 | やり方 |
|---|---|---|
| 単一ギャップ反復 | 理想のブースト角度を見つける | 同じジャンプを20回走り、1つの変数だけ調整する |
| ノーブーストクリア | 基本モメンタムを学ぶ | ブーストを一切使わずにセクションをクリアする |
| ブラインドブースト | タイミングの直感を築く | 視覚ではなく音やリズムの合図でブーストする |
| 逆走ルート | ベクトルの幾何を理解する | 既知のセクションを逆方向に走る |
| クールダウン計数 | 入力落ちをなくす | 1回のフルランでブーストの間に声に出して数える |

ルート計画にも同じ規律が必要だ。新しいセクションに挑む前に、そのクリーンなクリアを見て、必要だと思うベクトルの順番を書き出そう：水平、垂直、水平、リダイレクト。紙にルートをスケッチするプレイヤーは、ラン中の迷いが少ないと報告している。なぜならランが始まる前に判断が済んでいるからだ。

正直な注意点が一つ：正確なブースト値、クールダウン長、減衰率はゲームごとに異なり、同じゲームでもパッチによって変わることもある。ここまでの内容はVoid Runnersのブーストベクトルを考えるための枠組みであり、万能の数値セットではない。各原則を自分のビルドで試し、通用するものだけを残そう。

## よくある質問

### Void Runnersのブーストベクトルとは正確には何ですか？

ブーストを発動したときに適用される方向と大きさの組み合わせだ。矢印のように考えよう：矢印の長さが得られる速度の量で、向きがその速度の行き先だ。どちらの半分も同じくらい重要だが、ほとんどのプレイヤーは長さにしか注意を払わない。

### 常に最大強度でブーストすべきですか？

いいえ。最大の大きさが正しいのは、方向がすでに完璧で、前方のセクションが長く開けているときだけだ。狭い通路では、小さく角度の良いブーストのほうが生き残れる。ほぼすべての近距離状況で、精度は力に勝る。

### ブーストがまったく何もしないことがあるのはなぜですか？

最も可能性が高い原因はクールダウンウィンドウだ。多くの実装では、クールダウン中に押された入力はキューに入れられず破棄される。2番目に可能性が高いのは、カメラや向きの角度がブーストを無害な方向へ向けてしまい、無駄な押下に感じられることだ。

### ブーストベクトル操作が上達するにはどれくらいかかりますか？

プレイヤー体験によれば、単一ギャップ反復を数回集中して行うほうが、何週間ものカジュアルなフルランより大きな進歩を生む。このスキルは生の反射神経よりもパターン認識だ——ブーストが自分をどこへ送るか予測できるようになれば、実行はほとんど自動になる。
